# Dongzhi-Nan gprMax results

The 21 horizontal B-scans cover 3 m across the Dongzhi-Nan concrete slab. Each comparison places a color section of the model above the simulated Ex/Ey/Ez magnitude at the same distance from the right-hand start. The radargrams use the 256-level white-to-black palette embedded in the field GPR2 files.

The magnitude panels use 301 original traces per line with a fixed, realized 50 mm antenna separation and a 10 mm interval. Selecting this acquisition geometry suppresses the alternating vertical bands. A shared nonlinear amplitude scale allows weak and strong returns to be compared across lines. The signed Raw Ex companion shows all 601 original traces on their nominal 5 mm distance axis.
